# PICT-feb-2024

Data science and ML notebooks from a five-day session at PICT, February 2024.

## Contents

- Decision trees and random forest regression
- KNN
- Feature selection with wrapper methods (RFE, forward and backward selection)
- Sampling (cross validation, random under sampling)

Open the notebooks in Jupyter or Google Colab. The csv, json and xlsx files next to them are the datasets the notebooks use.
